# Bonus Academy 2026

Student web app for Bonus Academy. Next.js 16, React 19, the existing `bonus-academy` Firebase project, and the admin checkout API.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Checkout and promotions proxy to `NEXT_PUBLIC_ADMIN_API_BASE`. See `SYNC.md` for fields copied from the admin repo and `CUTOVER.md` before replacing the live Flutter site.
